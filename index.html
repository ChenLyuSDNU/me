Research

Questions and directions

Trustworthy & efficient code generation

How can code models produce correct, efficient, and secure programs — while making their decisions auditable? We study semantic guidance, execution-informed ranking, structured supervision, and explicit evidence in the generation process.

Related work KareCoder / IRCoCo / RankEF / SemGuard / EffiSkel

Efficiency: measurement, models, and alignment

Our efficiency work spans benchmarks, specialized models, and structure-guided learning.

GEC / ACEOB / E-code / SkelDPO / EffiSkel

Repository-level code security

How can we detect vulnerabilities and establish when they can actually be triggered? We investigate repository-level analysis, reproducible vulnerability assessment, and LLM-assisted CodeQL rule generation, repair, and evaluation.

Related work FCC / LLM ensembles for vulnerability detection

Security of code language models

How can code models remain reliable under adversarial inputs? Our interests include prompt-injection and jailbreak defenses, poisoning robustness, risk assessment, and guardrails for code generation.

Foundations in program representation and understanding

Earlier work studies API dependency graphs, tree-aware pretraining, and semantic code summarization.

ADG-Seq2Seq / TreeBERT / EnCoSum

Additional interests and technical topics

We also study deep architectures and their deployment in low-level vision, including Transformer, Mamba, and KAN models for super-resolution, denoising, and dehazing.

Other technical interests include low-memory code generation, safety-aware and constrained decoding, rollback, candidate ranking, efficiency/security evaluation, and evidence chains; joint coverage and quality metrics for CodeQL benchmarks; adversarial examples, exploit-chain risk assessment, red/blue teaming, and policy-compliant output filtering.

From explainable to auditable code — guided by rules, measured by evidence.
